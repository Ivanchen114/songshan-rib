# 教師查看學生視角

2026-09-26：新增教師學生視角；發布與正式站驗收記錄另見課程發布報告。

## 使用方式

1. 教師登入作品台，進入本週活動，選擇班級。
2. 在「查看學生視角」選座號／姓名，按「查看這位學生的畫面」。未交件的學生也可選。
3. 頁首顯示「學生視角 · 唯讀」及班級、座號、姓名。可用選單、上一位／下一位切換同班學生。
4. 按「返回教師畫面」回到原活動與班級；不需登出或取得學生六碼。

W3 小組／個人、W4、W5、W7、W8 題材／個人提案、W15–W16 共用入口；本機 W9 沿共用介面支援。W18 自願選件另有同一選單，合列教師可查看的班級。僅有上課教材、沒有作品台活動的週次，不另建立活動。

## 顯示與操作範圍

- 使用學生原本的畫面與讀取規則：本人作品、初讀任務、私人甲乙留言、AI 判讀、同題展廳、ORID、個人歷程及自願選件。
- 學生尚未送出對應 W5 判讀時，教師在學生視角也看不到繳交後才開放的依據；未發布的教師草稿、教師內部備註不混入。
- 教師唯讀預覽自動略過本學期展示說明，直接查看本週內容；不寫入學生同意紀錄。學生本人登入仍須完成原本的同意流程。
- 表單可打開查看，但保存、送出、上傳、抽題、公開設定等不寫入。伺服器另以明確讀取清單拒絕所有預覽寫入。
- 正式／測試帳號分開；停用學生、封存學期不提供假想登入視角，改由教師歷程查閱。
- 每次請求重新驗證教師身分、學期／班級範圍及學生有效狀態。不發學生 Session、不重設六碼、不更動正式學生紀錄。預覽只在目前分頁網址傳遞，不改其他教師分頁身分。

## 來源與驗證

前端 `workspace/student-preview.js` 共用於作品台、課程展廳及 ORID；伺服器 `workspace-server/student-preview.mjs` 由 HTTP 路由核權。沒有資料表或資料遷移。

117 項伺服器測試全通過；新增 4 項整合測試涵蓋學生視角相等、跨班／停用／跨學期／封存／測試隔離、全部寫入拒絕、教師權限撤回即失效，以及 W5 繳交前後內容開放。完整測試後加強 W5 開放案例，4 項再通過。網站建置通過。

本機 Chrome 以虛構資料完成：學生入口、上一位／下一位與選單切換、作品圖片、初讀任務、唯讀表單、返回教師、W18、W5 甲乙留言鎖定、ORID→同題展廳→ORID，以及 390px 手機版。內建瀏覽器本機換頁遇到導向／登入狀態異常，因此瀏覽器操作證據採 Chrome。正式 Google 登入、正式站及真實課堂操作尚未驗收。同步回課程工作目錄後，學生視角及 W9 共 8 項相關測試通過，既有 W8 整合介面保留。
