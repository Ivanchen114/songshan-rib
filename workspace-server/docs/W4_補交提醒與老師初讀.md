# W4 補交提醒與老師初讀

## 每學期操作

1. 學期管理沿用 W4 活動，啟用名單並開放交件。
2. W4 教師頁選班級，按「提醒未交者補交」，可填日期；留白依老師公告。預覽訊息與目前未交名單後發送。
3. 學生個人首頁（含首次登入說明頁）可見提醒；完成登入說明後按「補交 W4 作品」。提醒為站內訊息，沒有外寄郵件。只計有圖片的版本；空白、模糊或不符三格要求另由老師判斷。
4. 已發相同內容與日期不重複發送；補交後首頁不再顯示。新學期不沿用提醒、草稿或補讀紀錄。
5. 若讀者未回覆，在作品詳情按「由老師補上初讀」。先看圖、按需旋轉；AI 草稿由教師貼入、修改並保存。發布時明確确认已親自看圖及確認判讀，標示「老師初讀」或「老師初讀，AI 協助整理」。看不懂要寫出不確定，不猜情節。
6. 若只審閱 AI 內容，選「AI 模擬初讀」，標示「AI 模擬初讀，教師已審閱」。這種紀錄不能解鎖以真人回饋為依據的修改或保留流程。
7. 學生自己比較回饋、原意與畫面，在平台保存保留理由，或上傳 V2 並填修改依據；不要求一定修改。老師合看本人證據評閱，不自動算分。

## 歷程與界線

- 草稿只給老師；發布後本人可讀。發布與圖卡版本綁定，圖卡更新須重新看圖；既有發布文不覆寫。
- 原讀者任務不代填、不偽造完成，提示「已由老師補讀」；讀者後續回覆仍保留。
- 真人回饋與本人決定分開。作品未交、待初讀、待本人修改或保留、待教師核對分別呈現。
- 本人學期歷程及私人作品集可收錄已發布補讀，保留來源標示；不進公開展廳，草稿與其他學生提醒不外流。
- 公開設定、學生登入同意、既有甲乙留言與判讀作答、成績權重不變。
- 這次增加平台補救途徑；投影、歷程本、離線 HTML／PPTX、公開展廳與教材下載未換版。正常課堂的同學初讀仍照原流程；操作說明同步在平台「系統導覽與期末示範」。

## 維護

資料存在當期 W4 活動 legacy.w4Reminders 與 legacy.w4TeacherReadings；取出時只回傳本人所需欄位。既有資料庫快照涵蓋這些紀錄，無新增資料表。所有寫入核對教師班級權限、封存狀態與版本；補讀發布會改變評阅證據指紋，舊評分視窗須重新核對。提醒預覽核對名單指紋、發送時重新查詢；補交後即使遇到同時送出，首頁也不再顯示過期提醒。
