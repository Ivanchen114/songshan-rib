# R.I.B. 系統說明與維護

現行版本：2026-09-23 學期歷程、名單維護、離線作品集與導覽整合版。
正式入口：https://songshan-rib.vercel.app/workspace/
操作依本目錄「操作說明.md」；歷次部署證據另見 `cloud/production-status.md`，舊紀錄只解釋當時狀態。

## 系統分工

- Vercel：課程網站、作品工作區及同源 API。`workspace/` 是前端，`api/workspace.js` 轉接 `workspace-server/http.mjs`。
- Supabase PostgreSQL 私有 `rib` schema：學生、六碼驗證、教師權限、作品／版本、回饋、評閱、公開設定、學期與操作事件。瀏覽器不可直接讀表；伺服器核對每個請求的身分、班級、學期及作品歸屬。
- 私有 Cloudflare R2：上傳原圖、去除 EXIF 的閱讀圖與縮圖、封存來源檔及資料快照。上傳／閱讀採短效簽名，不能把物件金鑰或服務密鑰寫進前端。
- 舊 GAS、Sheets、Drive 保留為搬遷来源封存。六個既有活動已停寫，不雙寫、不要求學生重交。

## 身分、名單與學期

學生沿用八碼學號與六碼。搬遷的 salted SHA-256 在成功登入時升級 scrypt，明碼不變；系統不保存可還原六碼。Google 教師身分由 Supabase Auth 核對已驗證信箱，再查 rib 教師白名單；4057、5048 為管理教師，可查兩班。

`accounts.mjs` 負責查詢、重設六碼、停用／恢復；`roster.mjs` 負責當學期追加學生及姓名／座號更正。追加採預覽指紋、交易內再核對、衝突拒絕；只產生新生碼，不覆蓋既有學生。更正、重設、停用都讓舊登入失效；學號、作品外鍵保留。操作事件不記明碼或驗證值。

`terms.mjs` 保存新學期草稿、來源指紋、教師範圍與活動模板；啟用持有 workspace_state 排他鎖，一般寫入持有共享鎖，避免跨期交错。備份及讀回核對完成才切換。續讀六碼沿用；舊學期封存，新活動先停寫。首頁學期選單只是查閱，不改學生登入預設。

## 教學紀錄

W3 小組／個人、W4、W5 小組文字轉圖、W7、W15–W16 均由同一工作區保存；W18 選零至三個既有版本，不另建交件活動。W4 隨機讀者分配可處理奇數、晚交與補位，保留已完成初讀。作者改或留須有依據；教師評閱使用版本證據與並行更新核對，不自動判分。

`journey.mjs` 回傳指定學生已確認歸屬的各週作品；學生限本人學期，教師限授課範圍。僅傳必要文字、版本、初讀與本人改留，不傳他人身分、登入資料或教師分數。讀圖獨立核權，自己的歷史版本可讀，隱藏及正式／測試隔離仍有效。

`journey-ui.js` 整理選錄；`portfolio-export.js` 產生離線 HTML。圖片由伺服器逐張核權、縮為最多 1400px JPEG 後嵌入；每批 12 版本／36 圖及約 55 MB 上限。所有作者文字跳脫，離線檔 CSP 禁止程式執行與外連。私人初讀預設不匯出；小組成果不宣稱個人能力，紙本依據不新增重抄。

## 展廳與公開

課程展廳是登入後同活動兩班混展，作品編號不列作者，教師只看授權班；同班留言／欣賞票維持原規則。桌機三欄、平板兩欄、手機一欄；縮圖按需載入，放大才讀清晰圖。

對外匿名展廳另受 publication 狀態、登入同意、逐件不公開、教師停展及測試隔離控制。新作符合條件時自動展示；搬遷作品另需核對。不把勾選同意當成圖片已無個資；無自動遮字或人像辨識。作者撤回會停止展示及期末精選。

## 備份與復原

`backup.mjs` 的 rib-backup-v3 涵蓋 24 張持久表，驗證內容 SHA-256，兼容 v1／v2；只還原至獨立空白資料庫，活動停寫、登入須重新建立。還原活動與版本外鍵順序已測試；正式資料不得直接覆寫。

`maintenance.mjs` 每日建立 gzip 資料快照，存私有 R2 `backups/daily/`，讀回比較後才寫成功事件；重送同日已成功排程略過，失敗另記狀態。教師只讀成功時間與警示，管理員可手動觸發。排程 `/api/workspace-backup` 驗證 `CRON_SECRET`，由 Vercel 正式環境每日 UTC 19 時觸發（臺灣隔日凌晨約 3–4 點）；排程不保證整點，失敗不冒充成功。

每日快照**不包含圖片本體**，也不是另一個供應商的異地備份。完整離線備份用 `node workspace-server/scripts/backup-bundle.mjs <網站外的私密目錄>`，逐一保存圖片並核對 SHA-256，完成才寫 COMPLETE.json。至少在大量交件後、換學期或重要發布前執行；定期實際還原核對。現有圖片不可因資料快照完成就刪除。每日快照目前不自動刪除，維護者需定期檢查儲存用量與保留策略。

## 日常維護與發布

1. 課前用教師與隔離測試學生核對登入、選圖、保存、看圖；教室 Wi-Fi、真實相簿與整班操作仍需現場確認。
2. 課末先看沒有真人回饋的作品，再看交件數；故障時保留原圖與紙本，修復後回同一件作品接續。
3. 每週查看「系統維護」及雲端錯誤、資料容量、R2 用量；超過 48 小時沒有資料快照或有後續失敗即查核。免費額度不等於帳單硬上限。
4. R2 物件憑證交接到期日為 **2026-10-23**，到期前核對續換並實測讀寫。憑證只留私密環境與雲端 Secrets，不進 Git、網址或文件。
5. 正式發布使用隔離來源目錄，原課程目錄混有其他教材改動，不整包部署。跑 `npm run test:workspace`、`npm run build:site`，核對正式靜態檔雜湊與真實登入畫面；本機測試、部署成功、課堂驗收分開記錄。
6. 新站已有交件時，不可直接重開 GAS。先停止新寫入、保全新資料和圖片、在空白環境還原核對，再修復或移交。

## 導覽與文件

`workspace/guide.html` 為可分享的無個資模擬導覽，六段均可點選；樣本使用同一作品集匯出程式，不寫入學生資料。它說明系統用途，不能當作學生真實操作或能力證據。教師端的操作說明以現行功能為準，不再沿用驗收站時期「六碼管理尚未提供」等舊敘述。

相容入口：`/portfolio/?week=...` 導向新作品區，`/api/portfolio` 不再代理 GAS，W3 課堂 QR 已切換。`wall_comments`、`wall_votes`、`selections`、`activity_assets` 均置於私有 schema 並啟用 RLS；`works.current_version_id` 保留選用版本，`publications.featured` 仍須學生選件、可公開且教師已檢查。

## 小組歸屬與離組

`group-membership.mjs` 處理同班座號預覽、代表直接加入及本人離組。加入使用活動鎖，防止同時加入兩組；所有寫入由同源 POST、登入與學期封存檢查保護。離組在鎖內重新核對本人歸屬與作品 revision，保留 member 記錄（status=declined）及版本，不刪作品。作品 revision 遞增讓離組前準備的上傳失效；學生選錄在學生列鎖內移除該組版本。已有作品的離組會停展，教師核對後可恢復。

`group-upgrade.mjs` 僅供維護者一次性轉換舊 invited 名單，預設唯讀。先備份，再於工作區排他鎖內驗證有效同班、測試隔離及單一分組，轉成 confirmed 並記錄事件。保留舊制超過四人的既有分組，不擴張新建規則；已有版本的轉換保持停展，避免名單轉換自動擴大公開。
