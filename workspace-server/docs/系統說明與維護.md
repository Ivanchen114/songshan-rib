# R.I.B. 系統說明與維護

版本：2026-09-23，全週次整合正式啟用。此文件區分「已寫程式」「已部署」「已搬遷」「真人驗收」，不能互相代替。

## 系統分工

| 層次 | 服務／位置 | 工作 |
|---|---|---|
| 課程入口 | 原 songshan-rib 網站 | 課程、教材與原作品牆入口 |
| 新作品區 | `/workspace/` | 學生登入、作品、試讀、教師管理 |
| 伺服器 | Vercel Node API `/api/workspace` | 身分、權限、業務流程、上傳授權 |
| 主資料庫 | Supabase `songshan-rib` 私有 `rib` schema | 名單、驗證、作品版本、回饋、評閱及搬遷封存 |
| 媒體 | Cloudflare R2 私有 bucket | 不可覆寫原件、展示圖、縮圖 |
| 舊系統 | Google Sheets、Drive、Apps Script | 全部既有活動停寫封存，供復原與來源核對 |

學生不直接讀寫資料庫。圖片由瀏覽器取得短時上傳授權後直傳 R2，不再把整張圖片轉成字串送進 GAS。伺服器核對大小與 SHA-256，再產生 2400 px 展示圖與 480 px 縮圖。原圖私存，展示圖移除 EXIF。

## 身分與權限

學生維持八碼學號、原六碼及學期。搬遷保存原 salted SHA-256 驗證值；首次成功登入升級 scrypt，六碼內容不變。不保存可還原的學生六碼。

登入使用 HttpOnly、Secure、SameSite cookie，資料庫只存 session 雜湊。學生驗證版本變更時舊登入失效；教師每次核對仍在啟用名單及班級權限內。教師 Google 認證成功不等於擁有教師權限。

`rib` 表啟用 RLS，且不加入公開 Data API schema。API 使用專用 `rib_app` SQL 角色；前端不帶資料庫密碼或 R2 金鑰。R2 不開公開網址，只提供短時簽署讀取連結。CORS 僅列實際使用的來源。

## 核心資料

26 張表（24 張持久資料表、session 與限流兩張暫態表）分為名單與登入、活動與作品、回饋與改留、教師評閱與公開、媒體上傳、事件與搬遷封存。完整結構見上層 `schema.sql`。

作品每次保存形成新版本；每份初讀指向當時的版本。初讀完成後不覆寫，回覆另外保存。評閱核對證據指紋及修訂號，避免多人互相蓋掉。尚不能放入新流程的原紀錄保存在 `legacy_records`，來源檔案及雜湊保存在 `legacy_files`。

目前每 15 秒查詢更新游標，屬短輪詢；不是 WebSocket 即時推送。輸入中不強制重載表單。

1. 原 GAS 的 `MigrationExport.gs` 建立私人完整快照：原始各表、邏輯紀錄、學期指標、登入驗證雜湊及 Drive 檔案清單。

6. 切換後主資料以 Supabase 為準；不雙寫 Google Sheets。舊 Sheets／Drive 保留，不刪除。

只改網址回舊站不是完整還原。若新站已收新作品，須先停新寫入、保存新增資料與媒體，再逐筆移交或修復，避免遺失課堂紀錄。

## 日常維護

- 課前：確認網站、Supabase、R2 可用，用測試帳號實際登入、保存一張圖及讀回；確認本班階段與讀者安排。
- 課後：看未收到回饋名單、失敗上傳、教師待評閱項目；備份新增資料及媒體清單。
- 每週：核對免費用量、資料庫容量、R2 用量、登入失敗與伺服器錯誤；確認能從備份還原，而不只確認有備份檔。
- 變更部署前：跑權限／流程測試、部署到使用獨立資料庫的預覽環境、走教師與學生實際路徑。保留上一部署及相容資料結構。
- 憑證：R2 測試物件權杖於 **2026-10-23 到期**，到期前需續換，否則圖片上傳與讀取會失效。秘密僅放私密環境及雲端環境變數，不放說明文件、網址或 Git。
- 暫存：`incoming/` 一天後清理；原件與歷史版本不自動刪。未引用副本先核對引用再清理，不可整個刪除 `works/`。

免費方案有額度與限制。R2 包含超額計費，本程式的 8 MB 圖片上限及上傳限流不是帳單硬上限。Supabase 免費方案亦須另作備份與課前可用性確認。

## 學期管理與備份 v2

`workspace_state` 保存唯一目前學期；`term_drafts` 保存有修訂號的名單與活動草稿；`term_changes` 保存切換紀錄、備份位置及 SHA-256。三表位於私有 rib，RLS 僅授權伺服器 rib_app；瀏覽器角色無存取權。

切換由管理員執行，持有 workspace_state 排他鎖；一般作品寫入持有同一列共享鎖，避免配對、交件、評閱與切換交錯。草稿修訂號和來源指紋檢查名單、教師、登入碼修訂與活動設定；正式切換採單一資料庫交易。失敗不留下半份新名單或半套封存狀態。私人 R2 可能保留一次失敗操作的備份檔，這不代表學期已切換，應以資料庫紀錄為準。

每次切換前將 20 張持久表包成 `rib-backup-v2` JSON＋SHA-256，壓縮為 gzip 存入 `backups/terms/` 並讀回核對。媒體原件不搬動、不刪除；此檔是資料庫快照，完整離線復原還需要既有媒體備份。term_changes 只留索引，不內嵌前次快照，避免逐期膨脹。下載連結短時有效。

`backup.mjs` 的 `restoreEmpty` 可驗證並還原 v1、v2，只接受空白獨立目標，恢復後活動停寫、登入需重來。不能把舊快照覆蓋有新作品的資料庫。續讀者逐欄保留原憑證，新生只存 scrypt 驗證值；明文六碼只在產生後回傳一次給管理教師。

驗收部署維持 `RIB_ACCEPTANCE_ONLY=true`，伺服器拒絕 termActivate，並在 UI 隱藏正式啟用按鈕。termSave 只寫草稿。此限制不影響本機虛構資料的完整操作測試。

Supabase 最新安全檢查有一項 Auth 洩漏密碼檢查未啟用提醒（Google OAuth 與自訂學生六碼並非該密碼登入流程）；未為消除警示改動現有認證。若未來增加 Supabase 密碼登入，依[官方密碼保護說明](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)處理。私有資料表 RLS 沒有相關警示。


## 登入同意、逐件不公開與撤下

`agreement.mjs` 保存同意說明的固定版本與 SHA-256。學生按同意後，students.sharing_agreement 記錄版本、文件雜湊與時間，events 保存當時完整說明供追溯；同一版本重送不重複紀錄。每次請求由伺服器重新核對，未同意或版本過期者只能讀首頁說明、同意、登出或撤回展示，不能跳過頁面直接交件。教師帳號不受學生說明頁阻擋。

新學期名單不複製 sharing_agreement，因此須重新確認；不改原六碼。登入同意本身不發布任何舊作品、不變更逐件不公開設定。新交件由伺服器設定版本的 publicDisplay 與 sharingAgreementVersion，前端不再逐件詢問公開意願。

members.sharing_opt_out 保存每位已確認組員對該作品的例外選擇，任一人選擇不公開，列表與大圖端點都拒絕該作品。只有本人能改自己的選擇，教師發布也不能繞過。欄位加入時保留事件中最後一次明確撤回，不能將原 consent=false 的預設值直接視為學生曾拒絕。

works.publication_hold 另保存教師停展狀態；學生重新登入、同意或交新版本不能解除。兩種不公開互不覆蓋，課堂作品、回饋與評閱保留。

公開端點要求所有已確認作者已有目前的學期同意、無人選擇不公開、非測試帳號／活動、非隱藏與停展。gallery 回傳最多 24 件縮圖；galleryItem 每次核對後才簽署大圖。驗收站 RIB_ACCEPTANCE_ONLY=true 時始終不公開。既有圖片短連結仍可能在最多 120 秒內有效。

v1／v2 備份還原先驗證原始雜湊；舊資料缺 sharing_agreement 保持 null，缺 sharing_opt_out 補 false，缺 publication_hold 補 false。已有新設定的備份完整保留，不假造學生同意。27 項測試涵蓋首次登入、重送、換期、逐件選擇、小組防覆蓋、公開隔離與舊備份相容。

## 全週次增量整合

`course-upgrade.mjs` 只從已封存的邏輯紀錄補齊目前作品所需欄位：W3 文字、班內留言、既有選用版本及教師原圖。原始 `legacy_records`、媒體、學生驗證、既有回饋與成績不覆寫。重跑不新增重複活動／留言；此工具不是重新匯入名單。

## W4 第三階段補配

`reader-allocation.mjs` 使用隨機順序的二分圖增廣匹配，先分配已上傳作品，再分配尚未上傳的位置；這是有方向的閱讀責任，不要求偶數或兩人互讀。保留正常等待／已分派及完成紀錄，修補申請換件或本次缺席者未完成的任務。優先選尚無完成紀錄的空閒讀者，其次選完成份數較少者；每次每位讀者最多新增一份待辦。排除自己及同一作品的既有閱讀／換件紀錄。無解時回傳教師可見的作者座號、姓名與原因，不假稱全數成功。

分派持有活動、作品、回饋列鎖並檢查活動修訂號，與上傳、手動補位共同避免重複或漏接剛完成的 V1。展示階段允許新分派、回饋及有依據的保留／V2，但仍受封存、課堂保存開關、本人權限與測試隔離限制。不把展示後的回饋自動認定為未受提示的獨立判讀；已知原意者仍可申請換作品。

## 獨立班內展廳
