# W5 線上 ORID 與課堂署名（2026-09-25 發布版）

## 課堂流程

W5 每人上傳自己的圖 → 開課程展廳篩選同題 → 點「引用這件作品」 → 在自己的作品旁回答 O、R、I＋D。O 描述具體畫法或關係；R 寫感受，也可寫沒有特別感受；I＋D 寫學到什麼或如何用在自己的圖。2 分鐘欣賞、3 分鐘反思；可存草稿再送出。只存一份，不要求口頭發表或紙本重抄，不新增配分、不強迫 V2。已印第3頁欣賞欄可留白，全部 W5 學生紙本檔保持原樣。同題只有自己時先等同學，未完成者依原 W6 共同截止補存。

## 姓名與投票

W3 個人、W4、W5 的登入課程展廳顯示已確認作者姓名；小組列已確認組員。11501 學期 108／109 是共同上課的範圍。其他班不能透過改網址讀到這兩班的姓名、作品私有圖片或反思。教師仍遵守原班級權限，測試帳號隔離。

**W3 小組文字重建例外：先匿名投票。** 管理教師在活動頁按「結束投票並公布作者」並確認，才顯示姓名；已投票保留，後端停止新增／撤票。展廳按更新即可看到作者。重新開一般交件開關不會重新開票；這個活動不提供「看過姓名後再匿名重投」。新學期不繼承公布狀態。

共同班級邊界由 `workspace-server/classroom-audience.mjs` 的明確學期設定控制；未設定的學期只看同班，不自動混全校。維護者可於活動受信任設定 `legacy.classroomGroups` 指定互不重疊的共同班級。不能由學生請求的 className 參數擴張範圍。

## 反思資料與展覽

`works.reflection` 保存自己作品版本、引用作品／版本 ID、三問、草稿／送出狀態、修訂號；姓名查名單顯示，不拼入固定模板。修改保留事件紀錄，舊圖片版本不變，不需重新上傳圖片。草稿只有本人和授權教師可讀；送出後，課程展廳可讀。

學生可勾選反思隨作品匿名展覽。教師從該作品「查看 ORID／檢查匿名副本」核對文字，把文字中出現的姓名改成「參考作品 A」，保存展示副本；不更動學生原文。公開 API 只輸出該副本三問與匿名標籤，不輸出引用作品 ID、版本 ID、姓名、班級或私人事件。程式不宣稱可自動判斷自由文字中的所有個資。

公開仍遵守原作品公開／停展／不公開設定。學生修改反思即撤下已審反思副本，原圖不撤；重新檢查後才恢復文字展示。自己的圖版本改了，需重開反思核對，避免把舊反思審成新版本。

## 發布與資料相容

2026-09-25 已完成正式資料備份讀回及26表比對；本次僅套用 `orid-schema.sql` 的兩個可空 JSONB 欄位，再發布具名程式及教材，驗證正式隔離帳號。不得重設既有 Supabase／R2 或把所有未發布教材一起推上。

新增 API：reflection（本人／教師讀）、saveReflection（本人寫）、reviewReflection（授權教師匿名副本）、revealAuthors（管理教師結束W3投票）。寫入沿用現行學期鎖、活動開關與角色權限；反思有修訂衝突與重送檢查。既有整體備份會包含新增欄位，舊備份可還原為空欄位。
