# ORID 與班內匿名分享（2026-09-29）

本版取代2026-09-25的班內署名規則。所有週次的課程展廳均使用穩定的匿名作品代號；排序、切題、ORID引用與再次開啟仍能對上同一件作品。管理端與本人原始紀錄仍保留，既有同課班級、教師授課範圍及測試帳號隔離不變。

W3管理教師按「結束投票（保持匿名）」後只停止投票，已投票保留，不公布作者。為相容舊紀錄，內部仍使用authorsRevealed旗標與revealAuthors路由；旗標不再控制署名。

W5引用與展廳用同一個作品代號；ORID草稿限本人和教師，送出後班內匿名閱讀。W9同樣提供送出回饋，仍不建立對外反思副本。對外W5反思須經教師檢查，作者的公開意願與退出設定保持。

送出中鎖定按鈕；保存結果在按鈕附近顯示並移入可視範圍，區分草稿、送出與錯誤，可回自己的作品查看。失敗不清空輸入；不能把選取引用對象當作已送出ORID。

班內API的作品標籤及引用不傳姓名；分享文字中的本學期名單姓名及學號以「同學」替代，直接媒體的metadata亦採相同處理。這只產生讀取副本，不覆寫原始文字；本人與授權教師仍可核對原件。

照片像素、外部Canva頁面、暱稱或未列在名單中的個資不能保證自動匿名。各週上傳指引改為照片先遮姓名與班級座號、文字使用作品代號；紙本原件由教師核對。既有照片若仍有姓名，需另作去識別副本，不能以UI匿名宣稱已完成照片去識別。
