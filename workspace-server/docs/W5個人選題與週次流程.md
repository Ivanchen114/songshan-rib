# W5 個人選題與週次流程

依 2026-09-23 教師新決定，W5 文字轉圖改為個人，每人選一題交一張；原小組活動保留歷程，不將共同成果改列個人交件。

W5 操作：①選題（題號、標題、原文、讀者任務；明確確認，不預選）→②上傳一張（重列所選題目；換裝置仍可找回）→③看同題展覽（由教師開放課程展示）。已交件後題目固定，修訂保留同題版本；交件前可換題。

視覺：週次與個人／小組明示；步驟使用同一列編號，手機直排；當前可操作步驟只有一個主按鈕。題目內容展開後才選定；作品上傳不再額外選第二題。展覽題號選單不洩漏作者、班級座號，空題目顯示尚無作品。

其他週次核對：W3①小組先核對組員、看原圖與寫描述，再存兩次生成；W3②個人短文與一張圖。W4個人上傳→獨立初讀→本人改留；W7個人選材料→保存圖文→回讀修訂。W15–W16小組確認成員→選用途與形式→上傳／沿用→試讀修訂。W18自願選既有版本，不新建作品或增加作業。

沿用既有 Supabase/R2 登入與資料歸屬；SOIL 的清楚目的、步驟化及手機閱讀適用，本系統已獲授權使用雲端保存，非改為 localStorage。
