# W7 新聞 × 研究：均衡隨機分配（本機候選，未發布）

2026-09-24。新的小組活動 kind 為 `w7-news`；舊 `w7` 個人作品與動物園／手機題材保持歷史格式。

## 課堂操作

代表建立小組 → 用同班座號加入組員 → 核對名單 →「隨機分配本組題材」。
每組一次，組員登入共用同一份新聞與研究。抽題後製作一張紙本圖卡，由代表上傳；圖法自由。
四題為手寫與打字、延後上學時間、走路與創意、AI 數學家教。原始連結位於 `workspace/w7-topics.js`。
圖卡要能辨識新聞說法、研究依據、結論能說到哪裡、仍缺的資訊與出處。中文輔讀已附方法、結果及原文位置；截圖可自留，現場指回原文也可以，不新增截圖繳交欄位。有影響判斷的缺口才寫待查。
AI 題新聞與正式論文年份不同，入口已提示版本日期；走路題明標為校方研究新聞。

## 分配規則與保存

同一活動的兩班合併計數，每次優先選總組數最少的題材；若同樣少，優先選該班較少的題材，最後以伺服器亂數抽出。
18 個固定小組完成抽題後，四題為 5／5／4／4；哪兩題多一組不預先指定。各班盡量平均，不宣稱任意抽題順序都能達到個別班的固定配額。
活動列與作品列上鎖，計數、分配與事件在同一交易內完成。同組重按／重送／換人登入讀回同一結果，不重新抽。
沿用 `rib.works.topic`，無新增資料表。版本 metadata.topic 由伺服器綁定已保存題材，不能用上傳要求改題。
離組仍保留抽題紀錄；曾抽題組員重建小組不能再次抽題，分錯組須核對歷史後由維護者處理。更改正式分組可能影響目前組數分布，不能以清空紀錄當作一般重抽。

## 同題比較

課程展廳與匿名展廳可依題材篩選。課程展廳沿用師生登入、班級／測試隔離；匿名展廳沿用全組公開意願與教師管理，不公開姓名、班級或學號。
教師作品清單顯示各組題材。新增流程仍保留 V1／V2 與紙本回讀理由，不另加網站評分。

## 發布接續

目前只寫本機程式與虛構資料測試，未存取或改寫正式分配。
待W7 簡報與中文輔讀本機審閱通過、使用者授權發布後，先備份再執行 `setupW7News(db)` 讀取本期轉換計畫；核對後才以 `{apply:true}` 建立新活動。
轉換只處理目前學期，舊 W7 活動封存、所有作品與作者關係保留。新活動預設關閉，教師開放後才能抽題；測試活動與正式活動分開。
不重複建立相同學期／測試屬性的新聞活動。下一學期由既有學期管理沿用新 kind，無須另建同名活動。

## 本機驗收

- 全套 90 項測試通過（2026-09-24）；W7 新增 6 項整合測試。
