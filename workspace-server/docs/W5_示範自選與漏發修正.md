# W5 示範自選與漏發修正｜2026-09-29

## 設計原因

舊示範發放條件只找「沒有 W4 圖片上傳紀錄」的學生。已上傳但只有圖卡提醒、沒有可用甲乙者因此被排除。這是供應判讀材料的流程缺口，不能把「有上傳」視為「有可用甲乙」。圖卡待釐清與能否先做 W5 判讀應分開處理。

## 本次處理

依教師明確指示，為四位既有圖卡提醒且無甲乙的學生提供 A／B／C 三份既有範例，自選一份完成。同時在三選一入口、每份範例與原圖卡提醒中，告知各自暫無甲乙的原因及系統漏發原因。個別名單與備份留在私人維護紀錄，不放公開原始碼。

`w5DemoAssignments[studentId]` 新增 `choices` 陣列，每份有獨立 id、版本、圖片、甲乙及 taskNote。舊單份結構仍相容，不改既有七份分派與學生作答。示範不新增個人作品版本，不算補交或真人初讀，不公開內部判讀答案。

學生先預覽圖卡與甲乙，再選一份。第一次不得自動替學生選 A。已保存者重開同一份；改選須確認，開啟空白表單，不把原摘句或依據帶到新圖卡。舊儲存紀錄保留到學生再次保存；後端仍只保存該活動的一份判讀，檢查示範歸屬及版本。

## 自動名單修正（2026-09-29 已實作）

1. 把「發示範給未交 W4 圖卡者」改為「提供範例給沒有可用甲乙者」。名單判準須比照學生實際讀取權限：本學期有效活動、可讀且已發布、甲乙兩則皆非空。僅有提醒、草稿、撤回或無法讀取的留言均不能算可用。
2. 沒有可用甲乙且尚無範例者，預覽名單列出原因，教師確認後提供三份範例自選；不可僅看圖片數量或任意留言列是否存在。
3. 原 W4 補件與說明保留；不因發範例把學生改成未交，也不因做完範例判定原圖已修正。
4. 已有個人甲乙、已領單份範例、已有草稿／送出者不自動覆寫或換題。之後補上個人甲乙時，也不自動改掉學生正在作答的範例。
5. 名單預覽分開計算已有可用材料、待發放及需教師核對，不把草稿存在當成已有可用材料。
6. 每次開 W5 前核對名單：每位在籍學生至少有可用甲乙或可選範例，漏接人數必須為零。以未交、空白圖、情節不清、留言草稿、撤回、後補作品、重複發放及換學期測試；新學期不沿用舊分派。

教師後續授權立即修正自動名單。現已改為按學生可讀的完整甲乙判定，新發放統一三選一；預覽列出缺少材料的原因、覆蓋人數與需教師核對者。已有範例與作答不覆寫。這次程式更新不批次發放或改動既有學生紀錄。原「留待下學期」決定已被本次取代。
