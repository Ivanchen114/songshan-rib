# W9 查核後提案與 ORID（本機完成，尚未發布）

種類 `w9-check`。個人交件，每版一張p.1思考紀錄照片＋數位文字：候選與連結、採用來源APA、關鍵原文位置、核對結果、本人完整提案、AI協助一句話。p.2肉雞與另頁溫室題留紙本。NotebookLM筆記本不必公開，不另交Classroom。

W9三問回看今天課堂的一件事，沒有W5同題引用門檻。O客觀描述事情；R寫對這件事的感受；I+D寫對學習的發現與未來科目／任務的應用。三段接同一件事，各1–3句；不限定NotebookLM，可寫讀原文或同學交流，沒有特別感受也可以。

## 初始化與課堂開關

維護者使用 `node workspace-server/scripts/setup-w9-check.mjs` 先唯讀預覽；核對後以 `--apply` 初始化本期正式與測試活動。每種最多一個，重跑不重複建立，不更動作品、組員或W8活動。新活動預設 `production`、`accepting=false`；由老師在課堂開關勾開交件與保存。後續換學期沿用既有活動樣板，W8關係按學期、本人、測試範圍動態尋找，不沿用舊學期id。

W9在製作階段即可上傳、存ORID；是否開課程展示由老師決定，不是反思前置條件。僅共同上課班級可讀已展示作品；沒有線上互評。

## 版本與資料邊界

來源由伺服器找出本人同學期、同測試範圍的W8提案，保存當時work/version/activity id，拒絕信任前端提供的來源。尚無數位W8時允許紙本原作並明示尚未連結；有多件來源則要求教師核對。重傳不覆寫歷史版本。

ORID綁定自己的作品版本；存草稿、送出、重送、不同視窗衝突及舊版本保護沿用既有原則。補傳新照片不會暗改舊ORID版本，學生確認後保存才沿用。草稿限本人和授課教師，送出後在課程展示開放時同課班級可讀。教師入口唯讀學生原文，不產生W9反思公開副本。照片publicDisplay固定false，不自動上架。

## 本機驗證

`node --test workspace-server/tests/w9-check.test.mjs` 覆蓋一張照片與數位欄位、無採用來源時的搜尋缺口、來源由伺服器決定、個人歸屬、跨班／測試範圍、草稿／送出、重送、改版保護、教師讀回、展示與關閉。

`PORT=8985 RIB_DEMO_W9=true RIB_DEMO_GROUP=true RIB_DEMO_ALL=true node workspace-server/dev.mjs` 使用記憶體虛構資料，無正式學生；瀏覽器操作學生上傳、存草稿／重開／送出及教師讀回。

新版本以metadata.evidenceFormat=digital-v1識別；舊兩張圖片版本保留可讀，不改寫舊資料。資料、提案與照片同版保存，無額外資料表或草稿API。作業中先存NotebookLM記事或個人文件；交件表單尚未按保存前不自動保存。noSource允許缺APA／原文，但必須留搜尋詞與缺口，其餘判斷仍要本人完成。
