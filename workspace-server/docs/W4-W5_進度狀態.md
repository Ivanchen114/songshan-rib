# W4–W5 狀態與 W4 作者進度

2026-09-27：修正 W4 已有修改／保留紀錄便直接提示教師核對，以及老師真人初讀發布後進度條仍停在初讀的問題。

## 狀態

- 作品未交：還沒有作品版本。
- 待初讀：有版本，但沒有同學完成的初讀或老師已發布的真人初讀。
- 待本人修改或保留：已有真人回饋，尚無作者修改／保留紀錄。
- 已記錄修改或保留，待 W5 判讀：W4 已有作者決定，但同學期、同正式／測試範圍的 W5 判讀尚未送出。
- 已記錄修改或保留，W5 判讀待送出：W5 判讀仍是草稿。
- W4 與 W5 判讀已記錄，待教師評閱：W4 已有真人回饋及作者決定，對應範圍最新的 W5 判讀已送出。
- 已評閱：已有正式評閱紀錄。

這是平台紀錄進度，不保證内容已達標，也不代表 W5 另一份文字轉圖與 ORID 都已完成。W4–W5 原有評量條件不變；教師仍可依實際證據保存草稿、待補證據或正式評閱，不新增交件要求。

## 學生進度條

「上傳個人圖卡 → 取得真人初讀回饋 → 自己決定修改或保留」只描述自己的作品。
老師親自看圖並正式發布真人回饋後，作者進入第三步；草稿或僅 AI 模擬不推進。學生自己保存決定後三步顯示已記錄，接續提醒 W5 判讀。
學生替別人讀作品的任務保留在「我的初讀任務」，不會因自己的作品得到回饋而完成、取消或重分派。摘要提醒也以自己的作品進度為主，另外提示尚有讀者任務。

## 實作與驗證

前端共用 workspace/w4-progress.js，供作品狀態、學生下一步與進度條使用。W4 board 一次查回可見作品作者的最新 W5 判讀狀態，不回傳判讀正文；依學期、正式／測試、封存狀態與 W5 個人活動篩選。跨週狀態在開啟或「更新作品與回饋」時讀取。
測試涵蓋老師草稿→AI模擬→真人發布→本人保留→W5草稿→送出→退回草稿，以及跨學期、測試與封存隔離。無資料遷移、不改學生既有內容、不代學生送出。
