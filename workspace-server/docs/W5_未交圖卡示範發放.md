# W5：發示範給未交 W4 圖卡者

1. 教師登入作品區，選本學期的 W5 個人活動及班級。
2. 在「AI 留言判讀」按「發示範給未交 W4 圖卡者」。
3. 核對座號、姓名與 A／B／C 分派，按「確認發給以上同學」。每個班各做一次。
4. 學生回到 W5，按「看圖卡並開始判讀」。示範會清楚標示，依原有兩項填寫判色依據及改後一句。

名單以當下仍無 W4 圖片版本者為準；包括已建作品但尚無圖片者。已上傳全白、模糊或不符格式者不自動列入，需另判斷補件。重複操作跳過已發者；預覽後若有人補交，會要求重新預覽。A／B／C 按本活動已發數量均衡分配，不是能力分組。

示範不是學生創作，不建立 W4 作品或版本，不改未交狀態，也不替代真人初讀。學生後續补交不會刪除示範與既有判讀；若已開始示範作答，仍留在同份材料，不自動換題。若尚未開始，已有自己作品的甲乙留言時优先使用自己的材料。

每學期建立新活動後，分派名單從空白開始，不沿用上學期學生；三份固定示範可以重用。B 圖中 2026/09/26 是故事日期，不代表新學期的今天。不需要每學期重畫；要換題庫由維護者製作、教師審查後更新，已發出的圖卡與留言保持原版本。

學生只收到圖、甲乙、任務提醒；教師核對與修訂紀錄僅授課教師可讀，送出後也不自動公開。既有個人作品甲乙紀錄的開放規則不受此次示範功能影響。

技術：分派快照存於該 W5 活動的私有 legacy.w5DemoAssignments，沿用活動備份；沒有新資料表，也不進展廳。圖檔在私人 R2，伺服器核對本人或授課教師後簽署短效讀取網址。題庫伺服器模組不進公開網站輸出。
