## 程式與資料

- `setupW8Materials` 預設 dry-run；核准發布後才套用。為正式、測試各建立一組材料／個人交件活動，初始皆關閉；既有小組與抽題不更動。個人活動的 `legacy.materialsActivityId` 綁定其來源。
- 沿用 works/members/versions/uploads，不新增資料表。個人作品 owner_id 為本人；prepare 由已確認的來源小組查題材。metadata 保存 title、topic、sourceGroupId。
- 一張照片、既有直接上傳與去中繼資料流程；重試冪等、補傳版本、教師缺件、媒體權限沿用並驗證。
- 已讀材料活動可保持關閉，個人交件另開放；不能用學生提交的 group/topic 取代伺服器查核。
- 兩班登入展廳可看作者與同題作品。含紙本作者和提問者姓名，publicDisplay=false，不自動對外發布。對外仍須既有教師逐張檢查流程與作者意願，沒有授權在本次發布學生作品。
- 題材T1–T6保留；分流碼①②③由教師對照兩班名單指定，同題三組不重號。原組四人自行分好A、B、C、D；完整個人代號統一為`T1-②-A`（題材－分流碼－組員），寫在p.2空白角落。平台只保存題材，未新增自動混組分配。
