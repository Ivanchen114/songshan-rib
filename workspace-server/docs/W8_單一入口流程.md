# W8 單一入口與學生流程｜發布版本

## 畫面與行為

首頁每個有明確對應關係的 W8 只顯示「閱讀與個人提案」一張卡片。正式、測試、不同學期與封存狀態分開，不憑名稱合併資料。

進入後固定顯示「① 小組抽題與閱讀」「② 我的提案」，標示目前頁面。①由代表建立名單、以座號核對姓名、抽一次題；其他人更新後共用同題。全員先各自完成 p.1 第 01–03 題，四人分享與核對後各寫第 04 題。接著每人在 p.2 寫自己的提案，完成跨題交流並記下實際問句與修改或保留理由，才上傳。

②尚未抽題時只引導回①；已有題材但未開放交件時明寫先做紙本、等老師開放。尚無個人作品時按「紙本與交流已完成，上傳我的 p.2」直接開表單，不再先按建立作品。保存後顯示確認照片與交回整本的提醒；查看與補傳按鈕說清楚用途。課程展廳折疊在交件區後。離組功能收在「分組有誤時」，避免與主要任務並列。

課堂步驟依紙本與簡報，不根據按過閱讀連結就宣稱學生讀完。代表是小組自行選定；原系統未保存代表角色，因此不假設 owner_id 是代表，也不新增座號指定規則。小組題材與每人作品仍分別保存，權限、既有版本、公開規則與課堂開關不變。

教師在同一入口切換小組與個人查閱，保留班級選擇；抽題與交件仍可分別開關。首頁與內頁分別標明這兩種開放狀態。
