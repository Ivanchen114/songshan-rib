## 之後發布時的初始化

本次沒有連線變更正式活動或學生紀錄。下面是待發布步驟，不代表已執行：

1. 在已確認的正式環境用唯讀預覽：`node workspace-server/scripts/setup-reading-weeks.mjs`。
2. 核對當期及缺少的活動後，用 `node workspace-server/scripts/setup-reading-weeks.mjs --apply` 建立正式與測試活動。新增一律製作階段、關閉交件；不替老師提前展示。
3. 腳本依當期、種類與測試身分辨識，可以重跑；發現同類重複則停止，不再建同名活動。下一學期仍由既有換學期流程處理。
4. 正式部署後，以測試身分走儲存、重開、教師查看與權限；通過才由教師開啟正式課堂交件。
