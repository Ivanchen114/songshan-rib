# 多帶一支｜三圖微故事範例

教師自編虛構故事；圖片以 OpenAI image_gen 生成，並非學生原作或真實紀錄。

三張圖片，依序停留4、5、6秒，共15秒。此為檔案與操作示範，不是必須仿作的故事或唯一敘事格式。

- 示範_W5_V1_專案.json：在微故事工作台按「開啟專案備份」，還原圖片、字幕、順序、秒數，繼續編輯。也可上傳作品集。
- 示範_W5_V1.html：電腦用瀏覽器開啟按「播放」，不需網路或原圖檔，沒有編輯欄。手機優先開線上 HTML，或把 JSON 載回工作台按「只看作品」；手機檔案預覽不保證執行 HTML。

兩份檔案均由實際工作台下載按鈕產生。HTML不包含作者原意與改留理由；這些留在個人歷程本。
